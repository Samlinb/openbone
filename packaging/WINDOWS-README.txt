Openbone for Windows x64 / Windows x64 使用说明

简体中文
便携版：完整解压 ZIP，双击 Openbone.exe。请保留 app、runtime 等全部目录。
安装版：运行 setup.exe，点击“安装 / 重装”，再从安装目录启动 Openbone.exe。
Java 运行时、应用依赖和图形本地库均已包含，无需安装 Java、Maven 或下载依赖。
安装和日常启动不需要联网，也不修改 JAVA_HOME 或 PATH。
需要 Windows x64 和支持 OpenGL 的显卡驱动。
使用同一个安装器可卸载；用户工程和修改过的文件会保留。
恢复和布局数据默认位于 %LOCALAPPDATA%\Openbone，与安装目录分开保存。
命令行诊断：Openbone-cli.exe --version 或 Openbone-cli.exe --environment。
MCP：从编辑器的 MCP 菜单启动服务并查看连接信息，服务默认关闭。

English
Portable: extract the entire ZIP and double-click Openbone.exe.
Keep the app and runtime directories alongside the executable.
Installer: run the setup executable, install, then launch Openbone.exe in the chosen directory.
Java, application dependencies and native graphics libraries are included.
No Java/Maven installation or dependency download is needed on the user's computer.
Installation and normal startup work offline and do not change JAVA_HOME or PATH.
Windows x64 and an OpenGL-capable graphics driver are required.
Run the same installer to uninstall; user projects and modified files are retained.
Recovery/layout data lives separately in %LOCALAPPDATA%\Openbone.
Diagnostics: Openbone-cli.exe --version or Openbone-cli.exe --environment.
Enable MCP explicitly from the editor's MCP menu to view connection information.

Third-party application notices: THIRD_PARTY.txt and licenses/.
Bundled Java runtime notices: runtime/legal/.
