# 用实际项目需求迭代 OpenBone

## 目标

**用实际项目开发需求来迭代 OpenBone 工具的开发。实际开发过程中出现的任何问题，都可以用来改进 OpenBone 项目。**

OpenBone 的开发与真实内容制作持续配合。制作角色、骨骼动画、技能特效以及接入游戏时发现的问题，直接形成工具的需求和验收依据；改进后回到原来的项目，验证是否确实解决问题。

## 工作流程

1. **开展真实制作任务。** 明确项目、素材、期望效果和交付形式，通过 MCP 读取当前工程与可用能力。
2. **识别并记录问题。** 记录具体操作、输入、当前版本、实际结果和预期结果，区分素材问题、使用问题、工具缺陷与能力缺口。涉及连接时不得记录令牌。
3. **下发工具开发任务。** 将问题交给 OpenBone 开发聊天，说明阻塞的制作目标和最小必要改进。常规、已授权、可撤销的制作不因接口缺失反复要求用户确认；缺少接口时优先开发接口。
4. **实现并验证工具改进。** 复用现有应用服务、校验、撤销和模型语义，同步维护 MCP 接口、测试和说明。将问题转化为可重复执行的回归用例。
5. **交付可用版本。** 构建并验证实际运行版本，保护当前工程和未提交改动，说明升级方式与连接是否变化。无法自动延续连接时，明确需要用户执行的最小步骤。
6. **继续原始制作并验收。** 用新增能力完成原来受阻的操作，检查多个动画时间点、循环衔接和实际渲染结果；涉及游戏接入时还要在目标引擎验证。
7. **沉淀经验。** 记录问题、实现、验证证据及剩余限制，供后续角色和项目复用。工具改进与制作任务分别报告状态，避免把工具开发完成表述为内容制作完成。

## 改进范围与优先级

任何实际问题都可以进入改进记录，既包括功能缺失与程序错误，也包括 MCP 工具设计、文档、反馈、易用性、性能、资源流程及格式兼容。是否立即实现，取决于对当前任务的阻塞程度和可复用价值。

优先解决阻塞当前制作的最小完整能力，再处理已观察到的质量和效率问题。尚未影响任务的建议可以记录为后续需求，不为假设中的问题无限扩张当前版本。

AI 制作优先使用 MCP。接口不足时，应改进工具以支持正常制作；computer-use 不是默认替代方案，用户明确禁止时不得使用。外部脚本可用于素材准备与合法的格式处理，但不能将文件改写包装成实时编辑器操作或真实预览验收。

## 开发任务模板

- 原始项目与制作目标：要完成什么内容、达到什么效果。
- 当前版本与工程状态：已有资源、对象及可用接口。
- 问题与复现步骤：执行什么操作，实际发生什么。
- 预期行为：用户或 AI 应如何完成该操作。
- 本轮改进范围：解决阻塞所需的最小完整能力，以及可延后的项。
- 验收条件：真实 MCP 调用、可观察的编辑器结果、必要的渲染或引擎验证。
- 回归要求：相关失败场景、事务原子性、版本冲突、幂等重试、撤销和资源保存。
- 交付信息：构建产物、升级方式、连接状态、测试结果及剩余限制。

## 首个案例：俯视蚂蚁爬行动画

2026 年 10 月 26 日，GardenBattle 的真实需求是：使用 OpenBone 制作一只俯视蚂蚁，六条腿自然流畅地爬行，头部能摆动。

当时的 MCP 支持工程查询、动画与骨骼关键帧编辑、预览、撤销和重做；空白工程没有骨骼，接口也不能创建骨骼、导入 PNG 或绑定附件，因此无法开始搭建角色。

由此形成下一版开发任务：补充骨骼、插槽、贴图附件编辑，以及保存、平滑曲线、播放和取景等所需能力。验收必须包括通过 MCP 从空白工程搭建角色并查看真实预览，随后继续完成蚂蚁动画。此处记录的是需求来源与验收目标，不代表这些能力或动画已经完成。

### 0.1.3 的工具迭代结果

MCP API v2 已补充建骨、重设父级、插槽与顺序、PNG 区域附件、贝塞尔曲线、保存/加载、播放/暂停/精确定位、取景和干净预览。完整接口见 [MCP API v2](MCP_V2.md)。

已在测试窗口和实际 0.1.3 发行 JAR 中，使用官方 MCP 客户端从空白工程提交 188 个操作，创建 18 根骨骼、17 个 PNG 附件和六腿交替测试动画，取得真实 GL 预览，并验证保存、加载、撤销重做及播放控制。可复现脚本为 `scripts/mcp_scene_smoke.py`，测试证据位于 `target/mcp-ant-validation/`；实际发行窗口证据位于 `target/mcp-live-ant/`。

以上是工具链验收结果。诊断贴图与步态测试骨架不代表最终游戏素材、足部接触和动作自然度已经验收。随后回到 GardenBattle 原制作任务得到的结果另列如下，避免混淆两次验收。

## 后续改进记录

### MCP-CONN-001 重启后的连接衔接

**状态：已记录，后续迭代评估；本轮不实现，不调整正在运行的制作实例。**

来源是 2026 年 10 月 26 日 GardenBattle 蚂蚁制作聊天的实际反馈。继续制作时，聊天缓存的 `63289` 端口和上次 Codex 配置中的 `64326` 端口均连接被拒绝；当时 IDE 实例监听 `62876`，使用旧令牌收到 HTTP 401。这是制作聊天报告的现场状态，本记录不将这些临时端口视为固定配置，也未为记录问题重新探测或改动运行实例。不得在记录、日志或截图中附带实际令牌。

**影响：** 应用重启后，即使 MCP 已重新启动，客户端仍可能持有过期地址、凭据或工具参数表。机器缺少可靠的连接交接信息，导致制作中断、人工复制连接信息和反复重启客户端。工具能力本身可用，不等于原制作聊天已连接到正确的运行实例。

**本轮制作的临时处理：** 制作聊天随后确认，保留 IDE 窗口，新开 0.1.3 JAR 专用实例解决了连接，并完成正式蚂蚁制作。这是已报告的现场绕行方式，不代表连接衔接功能已经修复；本开发聊天不接管或修改该实例。

**现有能力与缺口：** 启动参数 `openbone.mcp.port` 和环境变量 `OPENBONE_MCP_TOKEN` 已能固定端口与令牌；菜单启动默认选择空闲端口，并在未配置令牌时随机生成。现有方式依赖外部启动配置，尚未形成菜单、IDE 启动与客户端之间完整的机器可读交接流程。

后续设计应评估以下方向，具体实现另立开发任务：

- 用户可选择并记住稳定的本地端口与凭据策略，明确区分普通重启、主动轮换令牌和停止服务；不得因自动重连而启动用户明确关闭的服务。
- 提供受本机用户权限保护的连接交接方式，供客户端取得实例标识、端点、版本和凭据引用。普通元数据、工程文件及日志不包含令牌；凭据存取方案需单独验证权限边界。
- 显示当前连接对应的实例与工程，处理端口占用和多窗口，避免悄悄连接到另一份工程或关闭仍在使用的实例。
- 对连接拒绝、401、旧版本与过期工具参数表给出不同的恢复说明。支持客户端热重连时优先使用；客户端不支持时，给出最短、准确的重新加载步骤，不承诺服务端能够强制刷新客户端缓存。

验收应回到实际制作聊天，至少覆盖：

1. 按选定策略重启应用后，客户端能取得正确连接并调用 `openbone_get_context`，确认实例、工程和 `mcpApiVersion`，继续原制作任务。
2. 主动更换令牌后旧令牌失效，新凭据可用；恢复过程中无令牌进入仓库、普通日志或测试产物。
3. 遇到端口占用、多实例、连接拒绝或 401 时，保留现有窗口与未保存编辑，清楚指出恢复步骤，不自动覆盖其他客户端配置。
4. 工具升级后明确验证新增工具参数表已加载；未刷新时不把写入配置描述为当前聊天已经接入成功。
5. 用户停止 MCP 后，重连或恢复程序不得擅自重启它；全程不以 computer-use 操作编辑器兜底。

当前只记录需求与验收条件，不执行重启、令牌轮换、端口变更或客户端重载，以免打断正在进行的蚂蚁制作。

### 本地 MCP 默认认证策略（2026-10-26 更新）

按用户要求，本地 MCP 默认可信，不使用交互密码，也不自动生成令牌。未配置或留空 `OPENBONE_MCP_TOKEN` 时，客户端只需 URL；仅在用户明确配置令牌时启用 Bearer 认证。仍保留回环监听、Host / Origin 校验和手动启停。上述现场记录描述的是修改前的行为；后续凭据交接和轮换验收仅适用于显式开启认证的连接。稳定端口、实例识别与客户端重连仍需单独完成验收。


### 稳定端口（2026-10-26 更新）

菜单默认连接地址固定为 `http://127.0.0.1:39871/mcp`；停止 MCP 后可通过“设置 MCP 端口”保存其他端口，重启程序后继续使用。优先级为 JVM 参数 `openbone.mcp.port`、环境变量 `OPENBONE_MCP_PORT`、用户保存值、默认端口。端口占用明确报错，不自动换端口，也不关闭其他实例。仅显式指定 `0` 时使用临时端口。默认免令牌；显式配置的 `OPENBONE_MCP_TOKEN` 不会被自动更换。端口持久化不存储凭据。


### MCP 控制窗口（2026-10-26 更新）

点击菜单栏 MCP 直接打开非模态控制窗口，集中设置端口、可选口令、自动开启 checkbox，并启动/停止服务、显示真实运行状态与地址。保存设置或启动时保存配置；默认自动开启关闭，是否自启动仅由保存的 checkbox 控制，端口启动参数不再隐含自启动。启动参数覆盖的字段为只读；运行中端口和口令锁定，停止后可修改。Windows 口令经当前用户 DPAPI 加密后保存，密码框默认遮蔽；加密与文件操作在后台执行。实际桌面测试覆盖启停、HTTP 认证、稳定重启、窗口重开、自动开启和关闭自启动，以及口令不明文写入配置。
